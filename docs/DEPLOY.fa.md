# راهنمای استقرار — آماده استفاده و قرار دادن روی سیستم

این سند برای **سرور شما (داخل ایران)** نوشته شده: از صفر تا اولین فایل اکسل
لیدها، بدون هیچ دانش فنی خاصی — فقط کپی کردن فرمان‌ها.

---

## ۰. چه چیزی نصب می‌کنیم؟ (۳۰ ثانیه)

ربات AbiiBot که این کار را خودکار می‌کند:

```
محصول هدف شما (مثلاً «لپ تاپ»)
   → جستجو در ترب → فهرست فروشنده‌های آن محصول
   → هر فروشنده فقط یک بار باز می‌شود:
        • شماره تماس و شهر و نام از API/صفحه ترب
        • اگر سایت اختصاصی داشته باشد → از سایت خودش هم شماره و ایمیل
        • اگر شماره فقط پشت دکمه «نمایش شماره» باشد → با مرورگر کلیک می‌کند
   → پاکسازی + حذف تکراری + امتیاز کیفیت
   → فایل اکسل/CSV در پوشه exports/ + دیتابیس data/leads.db
```

**پیش‌نیاز:** یک سرور Ubuntu/Debian داخل ایران با پایتون ۳.۱۰+ و git.
(چک سریع: `python3 --version` — اگر 3.10 به بالا بود، همه‌چیز خوب است.)

---

## ۱. نصب (یک فرمان)

```bash
git clone https://github.com/ali2000-did/abiibotv2gpt.git
cd abiibotv2gpt
bash scripts/install.sh
```

اسکریپت خودش: محیط مجازی می‌سازد، پکیج‌ها را نصب می‌کند، مرورگر کرومیوم را
آماده می‌کند و سلامت را چک می‌کند. اگر بخشی از اینترنت شما CDN خاصی را
می‌بندد، خودش راه جایگزین می‌رود.

## ۲. تست سلامت (توصیه‌شده — ۱ دقیقه)

```bash
bash scripts/selftest.sh
```

کل زنجیره را **بدون اینترنت** روی شبیه‌ساز محلی اجرا می‌کند: جستجو →
فروشنده‌ها → استخراج شماره → فایل خروجی. اگر آخرش ✅ دیدید، ربات روی
سیستم شما سالم است.

## ۳. اولین اجرای واقعی (روی ترب)

```bash
# محصول هدف شما — به‌جای «لپ تاپ» هر چیزی بگذارید:
.venv/bin/abii torob scan --query "لپ تاپ" --max-shops 50

# یا بسته آماده حوزه دیجیتال (۱۰ جستجوی پرتقاضا):
.venv/bin/abii torob scan --pack digital --max-shops 100
```

پایان کار، فایل‌ها را نشان می‌دهد:
```
exports/leads_torob_20260906_041200.xlsx   ← بازش کنید: نام فروشگاه، شماره، شهر، سایت، کیفیت
exports/leads_torob_20260906_041200.csv
```

**هر اجرای بعدی فقط داده جدید می‌آورد** (فروشگاهی که این هفته اسکن شده،
دوباره دانلود نمی‌شود) و اگر شماره جدیدی پیدا شود، به رکورد قبلی **اضافه**
می‌شود (چیزی گم نمی‌شود).

## ۴. تنظیمات (اختیاری ولی توصیه‌شده)

```bash
cp deploy/config.example.yaml config.yaml
nano config.yaml
```

مهم‌ترین‌ها: `workers` (سرعت)، `min_delay` (احترام به سرور)، `proxies`
(اگر IP بلاک شد). بعد از هر تغییر، `--config config.yaml` را به فرمان اضافه کنید:

```bash
.venv/bin/abii torob scan --config config.yaml --pack digital
```

## ۵. اجرای خودکار روزانه (روی سیستم بمانید و کار کند)

```bash
sudo cp deploy/abii-torob.service deploy/abii-torob.timer /etc/systemd/system/
sudo nano /etc/systemd/system/abii-torob.service   # مسیر و User را مطابق سرور خودتان
sudo systemctl daemon-reload
sudo systemctl enable --now abii-torob.timer        # هر روز ۴ صبح
sudo systemctl start abii-torob.service             # اجرای فوری همین حالا
journalctl -u abii-torob.service -f                 # دیدن لحظه‌به‌لحظه
```

(اگر systemd ندارید، همین خط را در crontab بگذارید:)
```
0 4 * * * cd /home/ubuntu/abiibotv2gpt && .venv/bin/abii torob scan --config config.yaml --pack digital >> logs/cron.log 2>&1
```

## ۶. مدیریت داده

```bash
.venv/bin/abii stats                        # چند لید دارم؟ چند تا شماره‌دار؟
.venv/bin/abii export --format xlsx         # خروجی کل دیتابیس هر وقت خواستید
.venv/bin/abii delete --phone 09121234567   # حذف یک شماره از همه رکوردها (حق حذف)
```

## ۷. شماره‌هایی که فقط با کلیک «نمایش شماره» ظاهر می‌شوند

حدود یک‌چهارم فروشنده‌ها شماره‌شان در API نیست و فقط با کلیک واقعی ظاهر
می‌شود. برای این‌ها حالت مرورگری دارید (کندتر، انسان‌گونه):

```bash
.venv/bin/abii browse -p torob --query "لپ تاپ" --max-products 10 --headed --record
# ویدیو و اسکرین‌شات جلسه در sessions/ ذخیره می‌شود
```

## ۸. رفع اشکال

| نشانه | راه‌حل |
|---|---|
| `blocked=…` در متریک و خطای 403 | IP موقتاً محدود شده: `min_delay` را ۳ ثانیه کنید، بعد از چند ساعت دوباره؛ یا پروکسی اضافه کنید |
| خطای `JSON نیست` یا خروجی صفر | ساختار API ترب عوض شده: `python3 scripts/probe_torob.py` را اجرا و خروجی zip را برای تیم فنی بفرستید |
| `کرومیوم نصب نشد` | `.venv/bin/python -m playwright install chromium` — یا بدون مرورگر ادامه دهید (حالت API مستقل است) |
| خروجی اکسل فارسی به‌هم‌ریخته است | فایل xlsx را باز کنید (CSV را با اکسل باز نکنید؛ xlsx از قبل RTL است) |

## ۹. به‌روزرسانی

```bash
git pull && .venv/bin/pip install -q -e . && bash scripts/selftest.sh
```

## ۱۰. یادآوری حقوقی

شماره‌ها داده شخصی‌اند؛ شرایط استفاده ترب جمع‌آوری خودکار را ممنوع کرده.
نرخ پیش‌فرض محافظه‌کارانه است ولی مسئولیت استفادهٔ مسئولانه (تماس هدفمند،
نه پیامک انبوه) با بهره‌بردار است. رکورد هر شماره با `abii delete --phone`
قابل حذف است.
