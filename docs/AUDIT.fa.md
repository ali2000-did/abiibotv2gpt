## ۲. نقص‌های پیداشده (رتبه‌بندی شدت)

### 🔴 P0 — باگ صحت داده (نمره قبل: از دست رفته)

**۲-۱. بازنویسی رکورد قوی با داده ضعیف.**
جریان `duplicate` فقط برچسب می‌خورد اما بعدش `upsert` بی‌قید اجرا می‌شد:
سناریوی واقعی: اسکن اول شماره فروشگاه را می‌گیرد؛ اسکن بعدی همان فروشگاه
را بدون شماره می‌بیند (API ناقص) → `duplicate` → با این حال رکورد قبلی
**بازنویسی و شماره برای همیشه حذف** می‌شد!
✅ **رفع:** `commit_lead` — duplicate فقط `touch` می‌شود (به‌روزرسانی last_seen)،
updated با `reconcile` ادغام می‌شود (اجتماع شماره‌ها + پر کردن فیلدهای خالی از قبلی).
تست: `test_commit_lead_duplicate_does_not_weaken`, `test_commit_lead_updated_merges_phones`

### 🟠 P1 — پایداری

**۲-۲. پاسخ 200 غیر-JSON کل اسکن را می‌کشت.** ‏`resp.json()` روی HTMLِ خطا
`JSONDecodeError` خام می‌داد که در دست `except (ConnectionError, BlockedError)` نبود →
کرش کل `asyncio.gather`.
✅ **رفع:** تبدیل به `ConnectionError` کنترل‌شده. تست: `test_get_json_non_json_raises_connection_error`

**۲-۳. 404 سه بار retry می‌خورد.** منبعی که وجود ندارد باید فوراً رد شود —
retry روی 404 هم وقت تلف می‌کرد هم بی‌احترامی به سرور بود.
✅ **رفع:** ‏404/410 → `None` بدون retry. تست: `test_get_json_404_returns_none`

**۲-۴. نبود قطع‌کننده مدار (Circuit Breaker).** اگر IP بلاک شود، ربات تا
ته لیست به کوبیدن سرور ادامه می‌داد.
✅ **رفع:** پس از ۱۵ بلاک متوالی، workerها متوقف و **نتایج جزئی ذخیره و خروجی می‌شود**.

### 🟡 P2 — پوشش داده و عملیات

**۲-۵. فروشگاه با API خراب = لید از دست رفته.** در دنیای واقعی همه
endpointهای فروشگاه سالم نیستند.
✅ **رفع:** fallback صفحه وب — اگر API جواب نداد یا شماره نداشت، HTML صفحه
فروشگاه با همان کلاینت محترمانه fetch و parse می‌شود (شماره‌های JS-injected
راستی‌آزمایی شد که از HTML خام درنمی‌آیند — فقط گذر مرورگری آن‌ها را می‌گیرد).
تست: بازیابی + مرزِ نتوان. بنچمارک: ۳ فروشگاه API-خراب ماک → ۳ بازیابی از وب.

**۲-۶. «حق حذف» در سند معماری وعده داده شده بود ولی پیاده نشده بود.**
✅ **رفع:** ‏`abii delete --phone 09…` (حذف همه رکوردهای یک شماره) + `abii stats` (آمار دیتابیس و اجراها).

**۲-۷. چرخش پروکسی فقط در کلاینت همگام.** کلاینت async فقط پروکسی اول را استفاده می‌کرد.
✅ **رفع:** round-robin روی همه پروکسی‌ها در `AsyncPoliteClient`.

**۲-۸. اسکریپت نصب مرورگر با cd می‌شکست + ffmpeg ندارد.**
✅ **رفع:** مسیر مطلق + نصب خودکار ffmpeg از npm + راستی‌آزمایی پایانی.
